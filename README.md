# Product Management System (PMS)

A backend application developed using Java and Spring Boot for managing product information through REST APIs.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST API

## Features

- Add a product
- Get all products
- Get product by ID
- Update product
- Delete product
- Exception handling
- DTO and Mapper implementation
- MySQL database integration

## Project Structure

- Controller - Handles REST API requests
- Service - Contains business logic
- Repository - Handles database operations
- Entity - Represents product data
- DTO - Transfers product data
- Mapper - Converts Entity and DTO
- Exception - Handles application exceptions

## How to Run

1. Clone the repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Configure the MySQL database in `application.properties`.
4. Run the Spring Boot application.
5. Test the REST APIs using Postman.

## Project Type

Java Spring Boot Backend / REST API / CRUD Application
